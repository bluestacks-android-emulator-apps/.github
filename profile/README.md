## Troubleshooting Common Issues

Install issues? Enable virtualisation in firmware when the installer reports it is missing.  
Performance problems? Lower the instance memory when Windows itself becomes sluggish.  
License/activation? Update the graphics driver if the environment renders a black screen.  
Compatibility? Recreate an instance that fails to boot rather than repairing it.  
Update failures? Check disk space before creating additional instances.
